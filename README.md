# 🛍️ Catálogo + Panel Admin

Catálogo de productos moderno y 100% estático, con panel de administración,
checkout por WhatsApp, links de pago (Stripe / MercadoPago), modo oscuro,
infinite scroll y todo listo para **GitHub Pages**.

## ✨ Características

- 🎨 Diseño moderno (glassmorphism, gradientes, animaciones fluidas)
- 🌗 Modo claro/oscuro persistente
- 🔍 Búsqueda en tiempo real + filtros por categoría + ordenamiento
- ♾️ Infinite scroll (carga 8 productos por lote)
- 🛒 Carrito persistente en `localStorage`
- 📲 Checkout por WhatsApp con mensaje pre-rellenado
- 💳 Botones de pago con **Stripe Payment Links** y **MercadoPago**
- ⚙️ Panel `admin.html` para gestionar productos sin tocar código
- 📦 Exportación de `products.json` + imágenes en un ZIP
- 🚀 Deploy gratuito en GitHub Pages
